# Daily Scrape Outputs

This directory contains the Markdown reports generated by the daily scrape job.

Each file is named `daily-scrape-YYYY-MM-DD.md` and contains:
- Statistics (articles scraped, curated, etc.)
- List of curated articles with summaries and scores
- Generated coding exercises

## How to Generate

Run the manual trigger:
```bash
pnpm trigger:scrape
```

The file will be created here automatically.
